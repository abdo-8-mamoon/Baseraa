# بصيرة – Your Eyes Are Your Safety (Prototype 1.0)

## وظائف هذه النسخة
- واجهة عربية متجاوبة قابلة للتثبيت كتطبيق PWA.
- تشغيل الكاميرا الخلفية وإيقافها.
- اكتشاف أجسام عامة باستخدام COCO-SSD عبر TensorFlow.js.
- رسم مربعات حول الأجسام وعرض اسمها وموقعها النسبي داخل الصورة (يمين/وسط/شمال).
- تنبيهات صوتية اختيارية بالعربية/الإنجليزية واهتزاز اختياري.
- التقاط صورة وتجربة Grayscale وNegative وBrightness وThresholding وEdge Detection التعليمية.
- OCR تجريبي عربي/إنجليزي باستخدام Tesseract.js.

## تشغيل محلي
يجب استخدام خادم محلي، لا تفتح index.html مباشرة. في VS Code استخدم Live Server أو شغّل:
`python -m http.server 8000`
ثم افتح `http://localhost:8000`.

## نشره على GitHub Pages
1. أنشئ repository جديداً.
2. ارفع كل الملفات والمجلدات كما هي إلى جذر المستودع.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. افتح رابط GitHub Pages في Chrome على Android.
5. اسمح للكاميرا. من قائمة Chrome اختر Install app أو Add to Home screen.

## ملاحظات
- تحميل TensorFlow.js وCOCO-SSD وTesseract.js يتم من CDN؛ يلزم الإنترنت عند أول تشغيل. النموذج قد يحتاج وقتاً على الهاتف.
- اكتشاف COCO-SSD يقتصر على فئات COCO العامة؛ لا يتعرف تلقائياً على الحفر أو السلالم أو الأرصفة أو كل أنواع المركبات المحلية.
- «يمين/وسط/شمال» تعني موضع الجسم داخل إطار الصورة فقط.
- لا توجد في هذه النسخة قياسات مسافة حقيقية أو تقدير عمق. حجم مربع الجسم ليس قياساً موثوقاً للمسافة.
- معالجة الحواف نسخة تعليمية مبسطة وليست Canny أو OpenCV الكاملة.
- OCR العربي قد تختلف جودته حسب وضوح الصورة والإضاءة واتصال الإنترنت.
- Service Worker يخزن ملفات التطبيق الأساسية فقط؛ النماذج وملفات اللغات الخارجية قد تحتاج الإنترنت.
- هذا مشروع أكاديمي تجريبي وليس جهازاً طبياً أو نظام سلامة. لا تستخدمه لتوجيه شخص أثناء المشي أو عبور الشارع، ولا تستبدل به العصا البيضاء أو المرافق.

## ملفات المشروع
- `index.html`: هيكل التطبيق.
- `css/style.css`: التصميم.
- `js/app.js`: الكاميرا، الاكتشاف، الصوت، المعالجة وOCR.
- `manifest.json`: إعدادات التثبيت.
- `sw.js`: التخزين المؤقت الأساسي.
